# Forms!






Forms are an essential part of web applications!

  - Often one of the very first topics that are taught as part of learning the basics of HTML
  - Looks straightforward to build at first glance
  - Real-world examples of web forms can have a lot of complexities!


















---
Here are some questions you might consider when building web forms with real-world requirements:

- What happens to the data when a user submits the form?
- How can we validate user inputs according to a certain set of requirements?
- How can we show error messages properly in case the user makes some invalid inputs?
- How can we keep track of the user inputs so that they don't lose progress when certain events refresh the page?
- How do we manage the application state so that we can make the above bullet points play nicely with each other?
